# SecureByte Password Hashing Benchmark

## Purpose

This benchmark records the actual performance of the Argon2id configuration used by the SecureByte password module.

The measurements are development-machine results only. They are not claimed as production response-time guarantees.

## Argon2id Configuration

The application uses the following configuration:

| Parameter | Value |
|---|---|
| Algorithm | Argon2id |
| Memory cost | 19456 KiB (19 MiB) |
| Iterations | 2 |
| Parallelism | 1 |
| Salt | Fresh random salt generated by the maintained Argon2 library |
| Stored representation | Encoded Argon2id hash |

A generated verifier confirmed the encoded parameter representation:

```text
$argon2id$v=19$m=19456,p=1,t=2
```

## Software Environment

- Node.js: v22.23.0
- Argon2 npm package: argon2@0.45.1
- Operating system/kernel: Linux 7.0.0-28-generic
- Architecture: x86_64

## Hardware Environment

- CPU: 11th Gen Intel(R) Core(TM) i9-11900H @ 2.50GHz
- Logical CPUs reported by the operating system: 16

## Benchmark Method

The benchmark uses the application's real `hashPassword()` and `verifyPassword()` functions from `src/services/password.service.js`.

For each benchmark execution:

- 3 warm-up hash/verification cycles were performed.
- 20 measured password hashes were performed.
- 20 measured password verifications were performed.
- The average, median, minimum, and maximum elapsed times were recorded.

No password hashes, salts, or stored credential values are printed by the benchmark.

## Results

### Benchmark Run 1

Password hashing:

| Metric | Time |
|---|---:|
| Average | 17.82 ms |
| Median | 17.94 ms |
| Minimum | 16.45 ms |
| Maximum | 18.87 ms |

Password verification:

| Metric | Time |
|---|---:|
| Average | 17.55 ms |
| Median | 17.57 ms |
| Minimum | 16.35 ms |
| Maximum | 18.71 ms |

### Benchmark Run 2

Password hashing:

| Metric | Time |
|---|---:|
| Average | 19.34 ms |
| Median | 18.91 ms |
| Minimum | 18.30 ms |
| Maximum | 21.38 ms |

Password verification:

| Metric | Time |
|---|---:|
| Average | 19.47 ms |
| Median | 19.04 ms |
| Minimum | 17.54 ms |
| Maximum | 23.43 ms |

## Summary

Across the two measured runs, the mean of the reported average hashing times was approximately 18.58 ms, while the mean of the reported average verification times was approximately 18.51 ms.

The measurements show some normal variation between executions. The project therefore records these as observed development-machine measurements rather than fixed authentication-response guarantees.

The SecureByte implementation retains the design configuration of Argon2id with 19 MiB memory, 2 iterations, and parallelism 1. Any future parameter change should be recorded as an explicit design decision and benchmarked again on the intended deployment environment.
